One original line of office comedy for make.fun's "Make the AI Judge Laugh: the Office Joke Open" bounty. A judge model compares jokes head to head, so the entry is a single sharp joke: the office printer jams, IT gets an email with a photo of the jam, and the printer itself replies with an out-of-office message.

## Run it

```sh
python3 main.py
```

Writes the joke to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
